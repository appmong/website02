전세는 큰돈이 오가는 계약이라, 몇 가지만 놓쳐도 보증금을 떼일 위험이 생겨요. 계약 전에 확인해야 할 것들을 순서대로 정리했어요. 관련해서 [전세보증금 반환보증](/housing/전세보증금-반환보증-가입/)도 함께 참고하세요.

## 1. 등기부등본부터 확인

계약 전 **대법원 인터넷등기소**에서 등기부등본을 떼어 확인하세요.

- **소유자**가 계약하려는 임대인과 같은가
- **근저당권·가압류** 등 빚이 얼마나 잡혀 있는가
- 내 보증금보다 **선순위 채권**이 많으면 경매 시 보증금 회수가 어려울 수 있어요

## 2. 시세 대비 보증금 점검

- 전세가가 **매매 시세에 육박(전세가율이 높음)** 하면 위험이 커요.
- 주변 실거래가·시세를 확인해 **과도한 보증금**은 피하세요.
- '깡통전세'(집값보다 보증금+빚이 큰 경우)를 특히 조심하세요.

## 3. 서류·신분 확인

| 확인 | 방법 |
| --- | --- |
| 소유자 신분 | 등기부상 소유자 = 계약자 본인인지 |
| 대리인 계약 | 위임장·인감증명서·소유자 확인 |
| 건축물대장 | 불법건축물·용도 확인 |
| 보증금 계좌 | 반드시 **소유자 명의** 계좌로 입금 |

## 4. 계약 후 즉시 할 일

- **전입신고 + 확정일자**를 이사 당일에 함께 받기(대항력·우선변제권 확보)
- 계약서·영수증 보관
- 가능하면 **전세보증금 반환보증(HUG 등)** 가입 → 떼일 위험 크게 감소

## 전세사기 예방 체크리스트

- [ ] 등기부등본 확인(소유자·근저당·선순위)
- [ ] 시세 대비 보증금 적정성
- [ ] 건축물대장(불법건축물·용도)
- [ ] 소유자 명의 계좌로 입금
- [ ] 전입신고 + 확정일자 즉시
- [ ] 전세보증금 반환보증 가입 검토

## 이런 신호는 조심

- 시세보다 유난히 **싼 전세**, **급하게 계약**을 재촉
- 등기부에 **빚이 많은데** 괜찮다고 안심시키는 경우
- 소유자가 아닌 사람이 **현금·타인 계좌**로 요구

전세는 '확인 한 번'이 보증금을 지켜요. 등기부·시세·보증가입 세 가지만 챙겨도 위험이 크게 줄어요. 구체적 판단이 어려우면 계약 전 전문가(공인중개사·법률상담)에게 확인하세요.
